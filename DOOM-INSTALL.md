# DOOM in PicoOS Pro v2.1

DOOM is included in the Pro USB image. The image contains both `doom.pico` and the shareware `doom1.wad`.

Boot the USB image through the UEFI path to use the app archive. Open Start and search for `DOOM`; it appears as a normal installed program.

The 1.44 MB legacy BIOS floppy image cannot carry the 4.2 MB WAD. The USB/UEFI image is the supported DOOM image.
